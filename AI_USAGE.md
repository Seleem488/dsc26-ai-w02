# AI usage

## Tools I used, and for which functions

I used ChatGPT when I needed help understanding the requirements and fixing some issues in `audit.py` and `metrics.py`. I also used GitHub Actions to check if the code was working correctly.

## One place where the AI was wrong, incomplete, or not what the spec said

Some code had extra Markdown formatting that caused Python errors. I noticed this when the GitHub Actions tests failed and fixed the formatting.

## The function I wrote without AI, and why

I used AI assistance to implement the functions, so I cannot claim that I wrote one entirely without AI. I ran the audit on the sample dataset, checked the output, and used GitHub Actions to verify the changes. This helped me understand how the implementation matches the requirements.
